## Rules

- 원본 데이터는 수정하지 않는다.
- `data/raw/`의 실제 데이터 파일은 Git에 커밋하지 않는다.
- 전처리 결과는 생성 코드와 함께 관리하고 원본에서 재생성할 수 있게 한다.
- API 키, 인증정보, 개인정보는 저장소에 저장하지 않는다.
- 외부 배포 제한이나 이용약관이 있는 데이터는 공개 저장소에 포함하지 않는다.
