## 폴더와 공유 정책

- `data/raw/`: 공공데이터포털 원본 CSV 498개. Git에서 제외하며 별도 팀 공유 저장소로 전달한다.
- `data/annual_revision/`: KICOX 연간보정본 XLSX 24개. Git에서 제외하며 별도 팀 공유 저장소로 전달한다.
- `data/existing/`: 이전 버전 마스터 대조용. Git에서 제외한다.
- `data/external/`: 배포 가능한 외부 보조자료 또는 소규모 집계 가공본. 파일별 출처와 조회조건을 함께 기록한다.
- `data/processed/`: 코드로 재생성한 최종 마스터. 코드와 함께 Git에서 추적한다.

팀원이 저장소를 clone한 뒤 완전한 오프라인 재현을 하려면 별도 전달받은 파일을 다음 위치에 배치한다.

```text
data/raw/*.csv
data/annual_revision/<구간>/*.xlsx
```

그 후 저장소 루트에서 실행한다.

```bash
python src/build_changwon_master.py --offline
python src/qa_master.py
```

## 관리 원칙

- 원본 데이터는 수정하지 않는다.
- 원본에서 재생성할 수 있는 전처리 코드와 출처 추적 컬럼을 함께 관리한다.
- API 키, 인증정보, 개인정보와 개인 조사메모는 저장소에 커밋하지 않는다.
- 외부 배포 제한이나 이용약관이 있는 데이터는 GitHub에 포함하지 않는다.
- 새 데이터를 추가할 때 출처, 수집일, 조회조건, 기간, 단위와 저장 위치를 이 문서에 기록한다.
