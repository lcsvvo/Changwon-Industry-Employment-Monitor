# 외부 준거 후보 감사 (external reference candidate audit)

작성 2026-09-18.

## 0. 이 문서의 성격

여기 나열한 자료는 **정답라벨이 아니다.** 행정 대응이나 사건이 실제로 있었는지를
보여줄 수 있는 후보를 놓고, 향후 독립 보조검증에 쓸 수 있는지만 심사한 기록이다.
현재 심사를 통과한 자료는 **0건**이며, 따라서 이번 작업에서 어떤 정량 성능평가도
수행하지 않았다.

기존 `data/reference/external_event_audit/README.md` 와 같은 원칙을 따른다.

## 1. 심사 기준

각 후보에 대해 여섯 가지를 묻는다. 하나라도 '아니오' 면 준거로 쓰지 않는다.

1. **분석단위 일치** — 업종 × 분기로 떨어지는가?
2. **창원국가산단 직접성** — 산단 경계 안의 사건인가?
3. **시점 특정** — 발생시점이 분기로 귀속되는가?
4. **대표성** — 특정 기업 1곳이 업종 전체를 대표하지 않는가?
5. **독립성** — 모형 입력과 같은 자료를 재포장한 것이 아닌가?
6. **선택편의** — 정책 신청행태·제도요건에 의해 선택되는 자료가 아닌가?

## 3. 항목별 근거

### 3-1. 고용유지지원금

- **공개 여부**: 지역 × 업종 × 월 단위 공개자료를 찾지 못했다
  (공공데이터포털 파일·OpenAPI 검색, KOSIS 확인, 2026-09-18).
  근접 자료는 `한국고용정보원_일자리지원사업_고용안정지원_고용장려금지원현황(월)`
  (2020-04 공표 기준, OpenAPI)과 `한국장애인고용공단_신규고용장려금 지역별 지급 현황`
  (연 1회, KSIC 대분류)뿐이며, 둘 다 고용유지지원금이 아니다.
- **선택편의**: 확보하더라도 신청·승인은 정책대상 요건, 기업의 신청 여력,
  제도 홍보 수준에 좌우된다. "지원금을 신청하지 않았다 = 위기가 없었다" 가 성립하지 않는다.
- **결론**: `status = NOT_AVAILABLE`. 향후 확보하더라도 **행정 대응 이력**으로만
  쓰고 위기 여부의 준거로 쓰지 않는다.
- **다음 단계**: 고용노동부 창원지청 대상 정보공개청구.

### 3-2. 산업단지 입주계약 체결·해지, 휴폐업 이벤트

- 공개된 것은 지자체별 '산업단지 입주기업 현황' 명부 스냅샷이며, 창원국가산단의
  계약해지·휴폐업 **이벤트 시계열**은 공개되어 있지 않다.
- KICOX 산업동향의 `firms_in` / `firms_op` 증감이 사실상 유일한 집계 경로이고,
  이는 **모형 입력과 같은 자료**다. 이를 준거로 쓰면 자기참조가 된다.
- **결론**: `status = NOT_AVAILABLE` + 독립성 요건 미충족.

### 3-3. 사업체 폐업 / 공장등록

- `경상남도 창원시_공장등록현황`(2024-12-31)은 실제로 내려받았다
  (`data/raw/external/changwon_factory_registry/`).
- 그러나 단일 시점 스냅샷이라 증감이 없고, 창원시 전역이어서 산단 경계와 다르며,
  등록/취소 시점이 파일에 없다.
- **결론**: `status = PARTIAL`, 준거 불가. 업체 구성 맥락 참고용으로만 보관한다.

### 3-4. 고용보험 상실자 급증

- 창원시 전역 모집단이며, 현재 확보된 것은 피보험자 **수준(stock)** 뿐이다.
  취득·상실 flow 는 KOSIS 인증키가 없어 수집하지 못했다.
- 업종 대응은 3개 업종만 가능하고 등급은 B(기계) / C(전기전자·운송장비)다.
- **결론**: 준거 불가. **방향 교차확인(cross-check)** 역할로만 사용한다
  (`data/processed/context/employment_crosscheck_panel.csv`).

## 4. 그래서 무엇을 했는가

준거가 없으므로 이번 작업은 **성능 재검증을 하지 않았다.**
대신 각 자료를 역할별로 분리해 배치했다.

| 자료 | 역할 | 섞으면 안 되는 것 |
|---|---|---|
| 고용보험 피보험자 | cross-check (같은 개념, 다른 출처·모집단) | 수준·점유율 비교, KICOX 값 대체 |
| 수출 / 전력 / BSI | context (다른 개념) | 업종 판정 입력, 업종별 배분 |
| 고용유지지원금·입주계약 해지 | external reference candidate (행정 대응) | 정답라벨, 정량 성능평가 |
| KICOX 최신 공표본 | vintage check (같은 계열) | 독립검증 |

## 5. 재심사 조건

다음 중 하나가 충족되면 이 문서를 다시 쓴다.

- 고용유지지원금이 지역 × 업종 × 분기로 공개되거나 정보공개청구로 확보됨
- 산단 단위 입주계약 해지·휴폐업 이벤트 시계열이 확보됨
- 고용보험 취득·상실 flow 가 창원시 × 산업중분류 × 월로 확보됨
  (KOSIS 인증키 발급 후 `src/data_collection/collect_kosis_employment_insurance.py`)
