# 업종 크로스워크 (industry_crosswalk)

외부 자료의 업종분류를 KICOX 10업종으로 옮길 때 쓰는 대응표다.
**이름이 비슷하다는 이유로 자동 대응시키지 않는다.** 모든 행에 등급과 근거를 남긴다.

## 파일

| 파일 | 원 분류체계 | 쓰이는 곳 |
|---|---|---|
| `employment_insurance_to_kicox.csv` | 고용보험 산업분류(창원상의 보고서 표기 / EIS 대분류) | 고용 교차확인 (3-1) |
| `ksic_to_kicox.csv` | KSIC 대분류·중분류 | 공장등록현황, 전력사용량 등 KSIC 기반 자료 |
| `hs_to_kicox.csv` | HS 부호 (류 2단위) | 초기 검토본. `hs6_universe_customs.csv` 로 대체됨 |
| `hs6_universe_customs.csv` | HS 6단위 (관세청 원본 기준) | **현행** 관세청 수출입 수집·집계 |
| `hs6_verified_to_kicox.csv` | HS 6단위 13개 | 초기 탐색본(기록 보존). 현행은 위 universe |
| `ecos_bsi_to_kicox.csv` | ECOS 업종코드 (KSIC 중분류) | 경기심리 맥락 |
| `labor_force_survey_to_kicox.csv` | 사업체노동력조사 산업 대분류 | 고용 flow (전부 등급 D) |
| `ppi_to_kicox.csv` | KOSIS 생산자물가지수 기본분류 | PPI 조정 생산 (3-3) |

## mapping_confidence

| 등급 | 뜻 | 자동 해석 제한 |
|---|---|---|
| A | 직접 대응. 범위가 사실상 같다 | 제한 없음 |
| B | 비교적 명확한 상위/하위 매핑. 범위가 한쪽으로 넓다 | 단일값 사용 가능하되 방향 해석까지만 |
| C | 복수 후보 / 부분포함. 가중치 근거 없음 | 밴드·방향만. 단정형 업종 신호 생성 금지 |
| D | 매핑 불가 | 업종 단위로 쓰지 않는다 |

`mapping_type` 은 관세청·KEPCO 같은 코드체계 자료에 대해
`direct` / `approximate` / `ambiguous` / `unavailable` 로 별도 표기한다.

## 사용 규칙

1. C·D 등급 행은 `industry_mapping_uncertain = True` 로 진단카드에 표시된다.
2. C·D 등급 자료로는 업종별 확인신호(`*_signal`)를 만들지 않는다.
3. 모집단이 다른 자료(창원시 전체 등)는 등급과 무관하게 KICOX 고용값을
   대체하거나 덮어쓰지 않는다. 방향 일치/불일치/비교불가만 계산한다.
4. 대응이 불확실한 품목을 억지로 업종에 배정하지 않는다. 남겨두고 `unavailable`
   로 기록하는 편이 낫다.

## HS6 모집단은 어떻게 만들었나

`hs6_universe_customs.csv` 는 손으로 고른 목록이 아니다.
관세청이 공표한 원본 두 개를 받아 기계적으로 만든다
(`src/evidence/build_hs6_universe.py`).

| 원본 | 쓰임 |
|---|---|
| `관세청_HS부호` (data.go.kr 15049722, 2026-01-01 기준) | HSK 10단위 → 앞 6자리로 유효 HS6 추출. 적용종료일자로 폐지 코드 제외 |
| `관세청_HSK별 신성질별_성질별 분류` (15049720) | 공표 `세번2단위품명`·`세번6단위품명` |

유효 HS6 **5,613개** 중, 류(2단위) 단위로 KICOX 업종 귀속 근거가 있는
**1,248개**만 수록한다.

| 류 | 품명(관세청 공표) | KICOX | 등급 |
|---|---|---|---|
| 72·73 | 철강 / 철강의 제품 | 철강 | A |
| 87 | 철도용 외의 차량과 부품 | 운송장비 | A |
| 89 | 선박과 수상 구조물 | 운송장비 | A |
| 84 | 원자로·보일러·기계류 | 기계 | B (전산기기 8471 등이 섞임) |
| 85 | 전기기기와 부분품 | 전기전자 | B |

**제외한 류**: 비철금속(74~81) — KICOX '철강'이 비철을 포함하는지 확정 불가.
광학·의료·정밀기기(90) — KSIC 27 대응이 불확실. 그 밖에 한 업종으로 귀속할
공식 근거가 없는 모든 류.

### 근거로 쓰지 않은 것

관세청 **신성질별 분류**(대분류 1.소비재 / 2.원자재 / 3.자본재)는 **용도별** 분류이지
생산 업종 분류가 아니다. KICOX 10업종과 축이 다르므로 대응 근거로 삼지 않았고,
참고용으로 열에만 보존한다.

그 결과 이 수출입 자료는 **업종 수출 총액이 아니다.** 근거 없는 류를 의도적으로
뺐기 때문이며, 모든 행에 `coverage_flag = mapped_chapters_only` 가 붙는다.
