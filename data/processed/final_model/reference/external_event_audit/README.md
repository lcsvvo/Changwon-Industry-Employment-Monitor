# External Events

공개 기업 사건으로 업종별 위기 여부의 외부 평가가 가능한지 살펴본 참고자료. **판정 입력과 정답 라벨로 사용하지 않음.**

| File | Content |
|---|---|
| `event_panel.csv` | 기업 사건 14건, 출처와 발생시점, 업종 연결 조건 |
| `event_panel_coverage.csv` | 180개 업종-분기의 사건 확인 범위 |

- **범위**: 2022Q1–2026Q2, 창원 소재 제조업 기업과 사업장. 조사일 2026-09-18.
- **라벨 조건**: 확정적으로 `label_usable=True`인 사건 0건. precision, recall 등 성능평가에 사용 불가.
- **기업과 업종**: 기업 사건은 업종 전체 사건을 뜻하지 않음. 기업별 산단 직접성과 업종 내 비중 확인 필요.
- **사건 미확인**: 정상 라벨이 아닌 unknown으로 유지.
- **자료편향**: 대기업 보도 편중, 발생일과 발표일 차이, 산단 경계 연결의 불확실성 존재.
- **독립성**: KICOX 수치를 재인용한 보고서는 독립된 외부 평가 근거로 사용하지 않음.
