# Notebooks

| Notebook | Role |
|---|---|
| [00](00_data_preparation.ipynb) | 원자료 정제와 분기 패널 구성 |
| [01](01_eda.ipynb) | 기술통계와 외부자료 탐색 |
| [02](02_q1_q2_q3_integrated_analysis.ipynb) | 생산, 고용 방향과 규모, 시간 분석 |
| [03](03_triage.ipynb) | 점검 단계와 판정 근거 |
| [04](04_model_evolution_and_experiments.ipynb) | 후보 모형 비교와 선택적 재검토 |
| [05](05_external_evidence.ipynb) | 외부자료와 채용 근거 |
| [06](06_final_results.ipynb) | 최종 결과 요약 |
| [07](07_professor_review_master.ipynb) | 자료 급변, 비교시점, 경계 민감성 등 보완 결과 |

- **읽는 순서**: 최종 결과는 `07`, 단계별 과정은 `00`부터 순서대로 확인.
- **입력과 환경**: [Data 안내](../data/README.md), [실행 안내](../src/README.md) 참고.
- **산출물**: [outputs/final_model/](../outputs/final_model/README.md)에 결과표와 그림 저장.
- **재생성**: Notebook별 역할에 따라 저장 결과를 읽거나 분석을 실행함. 전체 파이프라인 순서는 [RUNBOOK](../outputs/final_model/RUNBOOK.md) 참고.
