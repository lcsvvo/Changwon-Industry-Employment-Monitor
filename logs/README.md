# Analysis Records

현재 Notebook과 보고서가 참조하는 비교 코드와 저장 결과.

| Folder | Content |
|---|---|
| `experiments/electre_mrsort/src/` | Notebook 04의 후보 모형 설명과 비교 코드 |
| `experiments/archived_outputs/` | 후보 모형, 파라미터와 자료 민감성의 저장 결과 |
| `experiments/legacy_configs/` | 비교 코드에 필요한 파라미터 설정 |
| `experiments/sensitivity_history/` | 이전 규칙과 현재 규칙의 비교 기준 |
| `validation/` | 경계 민감성, 자료 정합성, 후속성과의 저장 결과 |

- **현재 참조**: 일부 분석, 보고서 생성 코드가 이 경로의 CSV와 모듈을 읽으므로 경로 유지.
- **해석**: 후보 모형의 결과와 현재 Triage 결과를 구분할 필요가 있음.
- **최종 결과**: [outputs/final_model/](../outputs/final_model/README.md) 참고.
