# 2026년 창원시 AI·데이터 활용 공모전 최종 기획안

## 1. 프로젝트 주제

### 창원국가산단 업종별 산업·고용 전환진단

#### KICOX 장기 패널을 활용한 생산·고용 상태, 고용 변화 규모, 국면의 지속·전환 분석


### 한 줄 설명

창원국가산단 10개 제조업종의 생산·고용 변화를 동일한 기준으로 결합하여 산업·고용 상태를 구분하고, 실제 고용 변화 규모를 확인한 뒤, 주요 업종의 국면이 얼마나 지속되고 어떤 경로로 변화해왔는지를 진단하는 프로젝트


---

# 2. 문제 정의 및 분석 필요성

창원지역에는 이미 산업·고용 관련 통계가 상당히 잘 정리되어 있다.

실제로 「2026년 1분기 창원지역 경제동향 조사」는 창원국가산단에 대해

- 생산
- 수출
- 입주업체수
- 가동업체수
- 제조업 가동률
- 고용

등을 함께 제시하고 있으며, 업종별로도 주요 지표의 전년동기 대비 변화를 제공한다.

따라서 본 프로젝트는

“창원에는 산업·고용 데이터가 부족하다.”

“기존에는 고용만 보고 있다.”

“생산과 고용을 처음 결합한다.”

는 문제를 제기하지 않는다.


## 우리가 주목하는 문제

기존 경제동향 자료의 주된 형태는

각 지표의 현재값
→ 전년동기 대비 증감
→ 업종별 수치 비교

이다.

이를 통해 어느 업종의 생산과 고용이 늘고 줄었는지는 확인할 수 있다.

그러나 업종의 산업·고용 상황을 보다 구체적으로 진단하기 위해서는 단순 증감률 외에도 다음 세 가지를 함께 볼 필요가 있다.


### ① 상태

같은 고용 증가·감소라도 생산 방향까지 같은가?


### ② 규모

같은 방향의 변화라도 실제 고용 인원 변화와 산업 내 비중은 얼마나 큰가?


### ③ 시간

해당 상태가 이번 분기에만 나타난 것인가?

여러 분기 이어지고 있는가?

과거에는 어떤 상태였고 어떤 경로로 현재 상태에 도달했는가?


예를 들어 생산↑·고용↓인 두 업종이 모두 같은 국면으로 분류되더라도,

한 업종의 고용 감소가 수십 명이고 다른 업종의 고용 감소가 수천 명이라면 산업 전체에서의 영향은 동일하지 않다.

또한 한 분기에만 나타난 생산↑·고용↓ 상태와 여러 분기 반복된 상태 역시 같은 방식으로 해석하기 어렵다.


## 따라서 본 프로젝트의 문제 정의는 다음과 같다.

이미 공개되고 있는 산업·고용 지표를 단순히 나열하는 것을 넘어,

생산과 고용의 결합 상태를 동일한 기준으로 분류하고,

실제 고용 변화 규모를 함께 확인한 뒤,

그 상태의 지속성과 전환경로를 시간축에서 추적할 필요가 있다.


즉 본 프로젝트의 차별점은 새로운 지표를 추가하는 데 있지 않다.

기존 공개통계를

상태 → 규모 → 시간

이라는 하나의 분석체계로 재구성하여 업종별 상황을 보다 구체적으로 진단하는 것이 핵심이다.


---

# 3. 최종 핵심 분석 질문

핵심 분석 질문은

상태 → 규모 → 시간

의 3단 구조로 구성한다.


## Q1. 상태 — 같은 고용 변화라도 산업활동 상태는 다른가?

업종별 생산과 고용의 전년동기 대비 변화 방향을 결합하여 업종×분기를 4개 국면으로 구분한다.


| 국면 | 생산 | 고용 | 의미 |
| --- | --- | --- | --- |
| S1 동반확대 | ↑ | ↑ | 생산과 고용이 함께 증가 |
| S2 생산확대·고용감소 | ↑ | ↓ | 생산과 고용의 변화 방향이 불일치 |
| S3 생산감소·고용증가 | ↓ | ↑ | 생산과 고용의 변화 방향이 불일치 |
| S4 동반감소 | ↓ | ↓ | 생산과 고용이 함께 감소 |


Q1의 역할은 각 업종×분기의 산업·고용 상태를 동일한 규칙으로 판정하는 것이다.

이를 통해 

같은 고용 변화 안에서도 생산 방향이 서로 다르게 나타나는지를 확인한다.


단, 국면은 업종의 좋고 나쁨을 판단하는 등급이 아니라

산업·고용의 현재 상태를 구분하기 위한 분류체계

로 해석한다.


---

## Q2. 규모 — 제조업 전체 고용 증감에는 어떤 업종의 변화가 큰가?

Q1의 4국면은 생산과 고용 변화의 방향을 보여주지만,

실제 고용 변화의 크기까지 보여주지는 않는다.

따라서 Q2에서는 다음을 확인한다.

- 업종별 고용 증감 인원
- 전체 제조업 고용에서 차지하는 업종별 비중
- 전체 제조업 고용 변화에서 각 업종의 변화 규모
- 상세 추적이 필요한 주요 업종


예를 들어

소규모 업종에서 50명이 감소한 경우와

주력 업종에서 1,500명이 감소한 경우는

모두 고용감소로 분류되지만 실제 산업 전체에 미치는 영향은 다르다.


따라서 Q2에서는

방향과 규모를 분리하여,

실제 고용 변화에서 어떤 업종을 중요하게 확인해야 하는지 근거를 마련한다.


Q2에서 선별한 주요 업종은

- Q3 상세 분석
- State Timeline
- 업종별 진단카드
- 보조지표 확인

등에서 우선적으로 다룬다.


단, 주요 업종 선정 기준은

정책 지원 우선순위를 자동 결정하는 기준이 아니라

분석과 시각화에서 상세 추적할 대상을 정하는 실무 기준

으로 사용한다.


---

## Q3. 시간 — 각 업종의 국면은 시간에 따라 어떤 경로로 전환되는가?

Q3에서는 Q1에서 확정한 분기별 S1~S4 state를 그대로 사용하여 시간축 분석을 수행한다.

즉 Q3 담당자가 별도의 기준으로 국면을 다시 계산하거나 재분류하지 않는다.


각 업종별로 다음을 확인한다.

- 동일 국면 연속분기 수
- 현재 국면 지속기간
- 최장 지속기간
- 최근 국면 경로
- 상태 유지 횟수
- 주요 전환경로
- 업종별 전환 빈도
- 전체 전환행렬


예:

S1
→ S1
→ S2
→ S2
→ S2
→ S4


이를 통해

한 분기의 일시적 변화와

여러 분기 반복·지속되는 상태를 구분하고,

업종이 어떤 상태를 거쳐 현재 국면에 도달했는지 확인한다.


단, 전환행렬은

미래 상태를 예측하는 확률모형이 아니라

과거 데이터에서 실제로 관측된 상태 전환 빈도

로 해석한다.


---

# 4. 세 핵심 질문의 연결 구조


전체 구조는 다음과 같다.


공통 분석 기준 확정

↓

Q1 상태 판정
+
Q2 고용 변화 규모 확인

↓

Q1 state 확정
+
Q2 주요 업종 선별

↓

Q3 지속·전환 분석

↓

가동률·업체수 등 보조분석

↓

주요 업종 산업·고용 진단카드

↓

후속 확인사항 제시


## 질문 간 관계

### Q1과 Q2

공통 데이터와 분석 기준이 확정되면 병렬로 진행할 수 있다.

Q1은 생산·고용 방향을 기준으로 상태를 구분하고,

Q2는 실제 고용 변화 규모를 확인한다.


### Q1과 Q3

Q3는 Q1에서 생성된 state를 사용한다.

따라서 Q1의 state 정의는 Q3와 반드시 동일해야 한다.


### Q2와 Q3

Q2는 Q3 계산의 필수 입력은 아니다.

다만 Q2에서 주요 업종을 선별하여

Q3에서 어떤 업종을 상세하게 보여줄 것인지 결정하는 역할을 한다.


따라서 세 질문은 각각 역할은 다르지만

최종적으로 하나의 산업·고용 진단 흐름으로 연결된다.

# 5. 공통으로 먼저 고정할 분석 기준

질문별 담당자가 개별 분석을 시작하기 전에

다음 기준은 공통으로 확정한다.


- 본분석 기간
- 참고기간
- 창원국가산단 10개 제조업종 기준
- 핵심 데이터 기준 버전
- 생산 변수 정의
- 고용 변수 정의
- 전년동기 대비 YoY 계산 방식
- S1~S4 state 정의
- 기본 국면 판정 기준
- 중립구간 민감도 기준
- N 처리
- INVALID 처리
- 결측 및 비교불가 분기 처리
- 최신 기준분기
- 주요 업종 선정 기준
- 데이터로 직접 말할 수 있는 범위
- 현재 데이터로 판단할 수 없는 범위


이 기준이 Q1·Q2·Q3에서 다르게 사용되면

각 분석 결과가 서로 연결되지 않으므로

공통 기준으로 관리한다.

# 6. 사용할 데이터


## 6-1. 핵심 데이터

핵심 분석 질문을 직접 구성하는 데이터는 다음 두 가지다.


| 데이터 | 활용 |
| --- | --- |
| KICOX 업종별 생산실적 | 생산 YoY 및 산업활동 방향 판정 |
| KICOX 업종별 고용현황 | 고용 YoY, 고용 증감 인원·비중 계산 |


### 기본 분석단위

창원국가산단 10개 제조업종 × 분기


KICOX 장기 패널을 구축하여

Q1·Q2·Q3가 동일한 데이터 기반을 사용하도록 한다.


---

## 6-2. 보조 산업활동 데이터

다음 지표는 독립적인 핵심 질문으로 구성하지 않고

주요 업종의 산업활동 상태를 보완하는 지표로 사용한다.


| 데이터 | 활용 |
| --- | --- |
| KICOX 제조업 가동률 | 주요 업종의 산업활동 상태 보완 |
| KICOX 입주업체수 | 기업 기반 변화 확인 |
| KICOX 가동업체수 | 실제 가동 기업 변화 확인 |


가동률·입주업체수·가동업체수는

생산·고용 4국면을 대체하거나

고용 변화의 원인을 직접 설명하는 지표로 사용하지 않는다.


---

## 6-3. 검증·보조 데이터

| 데이터 | 역할 |
| --- | --- |
| KICOX 연간보정본 | 분기 공표값 수정·보정 관리 |
| 생산자물가지수(PPI) | 명목 생산액의 가격효과 민감도 확인 |
| EIS 고용행정통계 | KICOX 고용과 통계 정의·방향 비교 |
| FactoryON | 필요 시 업종 내부 기업구조 후속 확인 |
| 고용24 | 필요 시 채용수요·직무구조 후속 확인 |


PPI와 EIS는 본분석 국면을 직접 결정하는 핵심 데이터로 사용하지 않는다.

특히 EIS와 KICOX의 고용은 통계 정의와 범위가 다르므로

수준값을 직접 결합하거나 하나의 지표로 합산하지 않는다.

# 7. 전체 분석 흐름


## STEP 0. 공통 분석 기준 및 데이터 정합성 확정

- 데이터 기준 버전 확인
- 분석기간 확정
- 업종·분기·변수 일치 확인
- 결측 확인
- YoY 계산 기준 통일
- S1~S4 정의
- N / INVALID 처리 기준
- 주요 업종 선정 기준
- 명목 생산액 한계 확인


↓


## STEP 1. 창원국가산단 산업·고용 장기 흐름 확인

- 산단 전체 생산·고용 흐름 확인
- 10개 업종의 생산·고용 규모와 비중 확인


목적은 단순 현황 소개가 아니라

업종별 분해와 규모 분석의 필요성을 확인하는 것이다.


↓


## STEP 2. Q1 — 생산·고용 4국면 분류

- 생산 YoY
- 고용 YoY
- S1~S4 분류
- 업종×분기 국면 분포
- 4국면 산점도
- 산업·고용 국면 히트맵


↓


## STEP 3. Q2 — 고용 변화 규모 분석

- 업종별 고용 증감 인원
- 업종별 고용 비중
- 전체 고용 변화에서 업종별 변화 규모 확인
- 상세 추적 주요 업종 선별


↓


## STEP 4. Q3 — 국면 지속·전환 분석

Q1에서 생성된 state를 그대로 사용한다.

- 동일 국면 연속기간
- 현재 지속기간
- 최장 지속기간
- State Timeline
- 주요 전환경로
- 상태전환행렬
- 전환 빈도


↓


## STEP 5. 보조 산업활동 분석

주요 업종을 중심으로

- 가동률
- 입주업체수
- 가동업체수

를 확인한다.


목적은 국면의 원인을 설명하는 것이 아니라

동일 국면 내부의 산업활동 차이를 추가로 확인하는 것이다.


↓


## STEP 6. 검증·민감도 분석

필요한 범위에서

- PPI 가격효과 민감도
- EIS 고용 흐름 비교
- 국면 판정 threshold 민감도

를 수행한다.


본분석 결과와 보조분석 결과는 구분하여 제시한다.


↓


## STEP 7. 주요 업종 산업·고용 진단카드 제작

Q1·Q2·Q3 결과와 보조지표를 한 장에 통합한다.


↓


## STEP 8. 후속 확인사항 제안

분석 결과만으로 정책을 자동 결정하지 않고,

주요 업종별로 다음 단계에서 추가로 확인해야 할 사항을 제시한다.

# 8. 핵심 분석 방법


## ① 기본 변화율

생산과 고용은 전년동기 대비 YoY를 기본값으로 사용한다.

분기 계절성 영향을 줄이기 위해 직전분기 증감보다 YoY를 중심으로 본다.


---

## ② 생산·고용 국면 분류

생산·고용 YoY의 방향을 결합하여 S1~S4를 정의한다.

본분석의 기본 판정 기준은 하나로 고정한다.

미세한 변화에 따른 국면 변화 가능성을 확인하기 위해

- ±0.5%
- ±1%
- ±2%

등의 중립구간은 민감도 분석에서 별도로 검토한다.


민감도 기준을 본분석 국면과 혼합하지 않는다.


---

## ③ 고용 변화 규모

Q2에서는 증감률뿐 아니라 실제 고용 증감 인원을 함께 본다.


확인 항목:

- 업종별 고용 증감 인원
- 업종별 고용 비중
- 전체 고용 변화에서 차지하는 변화 규모


이를 통해 소규모 업종의 큰 증감률이

전체 해석을 과도하게 좌우하는 것을 방지한다.


---

## ④ 국면 지속성

Q1에서 생성한 state를 기준으로

각 업종별 동일 국면의 연속기간을 계산한다.


- 현재 지속기간
- 최장 지속기간
- 반복 여부


등을 확인한다.


---

## ⑤ 국면 전환

t분기 state → t+1분기 state

의 실제 관측 전환을 계산한다.


- 상태 유지
- 상태 전환
- 주요 전환경로
- 전환행렬

을 확인한다.


단, 과거 전환 빈도를 미래 예측확률로 해석하지 않는다.


---

## ⑥ 보조지표 결합

가동률·입주업체수·가동업체수는

주요 업종의 상태를 보완하는 용도로 사용한다.


동일한 S2 업종이라도

가동률이나 업체수의 변화 방향이 서로 다를 수 있기 때문에

후속 확인사항을 구체화하는 데 활용할 수 있다.


다만

- 자동화
- 인력부족
- 외주화
- 구조조정

등의 원인을 해당 지표만으로 단정하지 않는다.

# 9. 분석에서 구분해야 할 해석 범위


## 데이터가 직접 말할 수 있는 것

- 업종별 생산 변화 방향
- 업종별 고용 변화 방향
- 생산·고용의 결합 상태
- 업종별 고용 증감 인원
- 업종별 고용 비중
- 관측된 국면 지속기간
- 관측된 전환경로
- 가동률·업체수의 동시 변화
- 보조 데이터 적용 시 결과의 민감도


## 간접적으로 시사할 수 있는 것

고용 증감 하나 또는 한 분기의 수치만으로

업종의 산업·고용 상황을 충분히 구분하기 어렵다는 점


## 현재 데이터만으로 말할 수 없는 것

- 자동화 때문에 고용이 감소했다.
- 인력부족 때문에 고용이 감소했다.
- 외주화 때문에 고용이 감소했다.
- 생산↑·고용↓ 업종은 문제 업종이다.
- 특정 업종에 특정 정책을 우선 지원해야 한다.
- 정책이 현재 고용 변화를 발생시켰다.
- 과거 전환 빈도로 미래 국면을 예측할 수 있다.

# 10. 기존 자료와의 차별성

기존 창원지역 경제동향 자료는 이미

생산·수출·가동률·입주업체·가동업체·고용과

업종별 증감률을 제공하고 있다.


따라서 여러 지표를 함께 본다는 것 자체는 차별점이 아니다.


| 구분 | 기존 경제동향자료 | 본 프로젝트 |
| --- | --- | --- |
| 분석형태 | 분기별 현황·YoY | 장기 업종×분기 패널 |
| 생산·고용 | 각각 수치·증감률 제공 | 두 지표를 결합해 상태 분류 |
| 고용 규모 | 업종별 현황 제공 | 증감 인원·비중을 활용한 규모 분석 |
| 시간축 | 시점별 비교 | 국면 지속기간 및 전환경로 분석 |
| 가동률·업체수 | 현황값 제공 | 주요 업종 상태의 보조 해석 |
| 업종 비교 | 표·증감률 중심 | 상태·규모·시간을 함께 비교 |
| 최종 결과 | 경제현황 파악 | 산업·고용 상태와 변화 경로 진단 |


## 핵심 차별성 문장

기존 경제동향 자료가 각 산업지표의 분기별 현황과 증감률을 제공한다면,

본 프로젝트는 동일한 KICOX 업종을 장기간 추적하여

생산·고용의 결합 상태를 일관된 규칙으로 분류하고,

실제 고용 변화 규모를 함께 확인한 뒤,

해당 상태의 지속기간과 전환경로를 정량화한다.

# 12. 정책 연결지점

본 분석은 특정 국면을 특정 정책에 자동으로 매칭하지 않는다.


예를 들어

S2 → 인력정책

S4 → 금융지원

처럼 기계적으로 연결하지 않는다.


대신 본 분석을

기존 산업·기업지원 업무를 위한 사전 진단자료

로 위치시킨다.


## 활용 구조

기존 산업동향 자료

↓

Q1 업종별 산업·고용 상태 확인

↓

Q2 실제 고용 변화 규모 확인

↓

Q3 지속·전환 확인

↓

가동률·업체수 등 보조지표 확인

↓

추가 확인사항 도출

↓

기업 현장확인·산업지원·일자리 정책 검토 시 참고


연결 가능한 기존 정책 영역은

- 창원형 강소기업 육성
- 중소기업 육성자금
- 기업 애로지원
- 산업전환 인력양성
- 청년일자리

등이 있다.


다만 분석결과만으로

지원 대상을 자동 결정하거나

특정 정책의 필요성을 확정하지 않는다.

# 13. 기대효과


## ① 같은 고용 변화의 상태 구분

고용 증가·감소만으로 묶였던 업종을

생산 방향까지 함께 고려하여 구분할 수 있다.


## ② 실제 고용 영향 규모 확인

증감률뿐 아니라 실제 고용 증감 인원과 비중을 확인하여

산단 고용 변화에서 영향이 큰 업종을 구분할 수 있다.


## ③ 일시적 변화와 지속적 국면 구분

한 분기 상태와 여러 분기 반복·지속되는 상태를 구분할 수 있다.


## ④ 산업 변화의 전환경로 확인

업종이 어떤 상태를 거쳐 현재 국면에 도달했는지 시간축에서 확인할 수 있다.


## ⑤ 기존 경제동향 자료의 해석 보완

새로운 통계를 대체하는 것이 아니라

기존 공개통계를 재구성하여

상태·규모·시간이라는 추가 분석층을 제공한다.


## ⑥ 후속 현장조사의 구체화

데이터만으로 원인을 과도하게 설명하지 않고,

다음으로 확인해야 할

기업·채용·직무·산업활동 정보를 구체화할 수 있다.


## ⑦ 반복 가능한 분석체계 구축

KICOX 분기 데이터가 새로 발표될 때

동일한 규칙으로 반복 적용할 수 있는 분석틀을 구축한다.

# 14. 프로젝트의 한계

1. 생산액은 명목액이므로 가격변화가 포함될 수 있다.

2. KICOX 고용인원만으로 고용 변화 원인을 판단할 수 없다.

3. 업종 내 개별기업 차이를 직접 보여주지 못한다.

4. 국면은 상태 분류이지 좋고 나쁨의 평가가 아니다.

5. 고용 변화 규모가 크다는 사실이 곧 정책 지원 우선순위를 의미하지 않는다.

6. 과거 전환 빈도는 미래 예측확률이 아니다.

7. 가동률·업체수의 동시 변화만으로 생산·고용 변화 원인을 판단할 수 없다.

8. PPI와 EIS는 본분석과 정의·범위가 다르므로 보조분석 범위를 넘어 해석하지 않는다.

9. 정책효과 및 인과관계는 본 분석에서 검증하지 않는다.

“이번 분기 생산과 고용이 얼마나 늘고 줄었는가?”에서 끝나지 않고,
