# EDA 실행 결과

## 분석 결정

- 본분석 국면은 KICOX 명목 생산액 YoY와 고용 YoY로 계산한다.
- PPI는 선택 후보에 한정한 민감도 분석이며 실제 물량이나 생산성을 뜻하지 않는다.
- EIS는 모집단이 다른 고용 지표의 방향 비교이며 KICOX 정확성 검증이 아니다.
